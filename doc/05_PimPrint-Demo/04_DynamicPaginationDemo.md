# DynamicPaginationDemo

PimPrint supports dynamic pagination of InDesign documents.

The [DynamicPaginationDemo](https://github.com/mds-agenturgruppe/pimprint-demo-bundle/tree/4.x/src/Project/DynamicPaginationDemo/ColumnPagination.php) is an example of how to
use dynamic column breaks in conjunction with automatic pagination.
